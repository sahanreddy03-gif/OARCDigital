## Editorial rules

- Show one fact only when its wording matches an identified source.
- Use a direct public verification link when one exists.
- Label an OARC-owned product clearly; never imply that it is a client engagement.
- Use supplied project media only in the associated approved case.
- Omit a metric, testimonial, date, or service when the source is not approved.

## Credibility review checklist

- [x] Public card uses approved PJAZZA project media and identifies it as OARC-owned.
- [x] PJAZZA page names the product, explains the OARC relationship, and links directly to the public product site.
- [x] Visible PJAZZA facts match the public product page.
- [x] Unsupported dates, results, testimonials, superlatives, and feature claims are absent.
- [x] Metadata, canonical URL, JSON-LD, visible copy, and accessible image text describe the same project.
- [x] Unverified records are withheld from public proof surfaces.
