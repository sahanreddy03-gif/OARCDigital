2 — Background & particle / neural grid system (developer-ready)

Recommended tech
	•	Primary: three.js (WebGL) for full control of nodes, depth, and GPU performance.
	•	Faster alternative: tsParticles for particle systems (easier to integrate).
	•	SVG animations / overlays: Lottie (JSON) for light-weight vector micro-animations (e.g., pulsing ring).

Why three.js? You need depth (parallax), line connections, and controlled GPU performance — three.js is ideal.

Visual design and parameters (copy/paste for dev)
	•	Canvas size: full-bleed hero & site background (cover, fixed).
	•	Particle count (desktop): 120–180 nodes.
	•	Particle count (tablet): 60–100.
	•	Particle count (mobile): 16–28 (or disable and show Lottie fallback).
	•	Node radius: 1.2–3 px (varies by depth).
	•	Line length threshold: 140px (connect nodes when within threshold).
	•	Glow: additive bloom post-process (soft), intensity 0.6.
	•	Colors: node = #00D1FF (cyan) / #8A5FFF (purple) mix; connecting lines = rgba(255,255,255,0.06) with neon accent when active.
	•	Parallax: camera movement on pointer scroll — small: max 6–12px offset on X/Y.
	•	Movement speed: slow drift 0.2–0.6 units, easing Sine.InOut.
	•	Interaction: nodes pulse (scale 1 → 1.3) and show label on hover/click. Click opens mini-card (title + 1-line + CTA).

Performance & fallback rules
	•	Use requestAnimationFrame throttling; pause animation when tab inactive.
	•	On mobile detect device memory / prefers-reduced-motion: reduce particles to <20 or render static Lottie poster.
	•	Provide poster PNG / responsive images for non-WebGL fallback.

Example three.js behaviour (not full code, but spec)
	•	Create InstancedMesh for nodes (cheap rendering).
	•	Use a LineSegments buffer to draw connections (update every 10 frames).
	•	Add bloomPass for glow effect (postprocessing).
	•	On node click, sample contextual data and animate mini-card overlay.

5 — Animation & micro-interaction specs (exact)

Use these values across the site for consistency.

General
	•	Easing: cubic-bezier(.22,.9,.35,1) for motion in, cubic-bezier(.4,0,.2,1) for out.
	•	Default animation duration: 320ms (buttons), 420–600ms (modals), 900–1200ms (hero intro).
	•	Parallax intensity: 6–12px max.

Counters / KPI animation
	•	Count-up duration: 900ms (0 → target) with easeOutCubic.
	•	When visible on scroll: trigger when 50% of element visible.

Flow-lines
	•	Travel speed: animated dashed line with phase = 1.6s loop
	•	Glow pulse on active links: 600ms ease-in-out loop

Modal
	•	Entrance: scale(0.96) + opacity 0 → scale(1) + opacity 1, duration 420ms.
