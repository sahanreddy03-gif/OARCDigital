CONTENT GENERATION RULES
=========================================================

For all 50 pages, content must be GENUINELY UNIQUE:

1. UNIQUE LOCALITY/MARKET ANGLE
Each page references specific Malta context:
- For Tier A: Industry-specific Malta data (iGaming sector 
  size, fintech regulations, hospitality trends)
- For Tier B-E: Malta-specific use cases or examples
Generic "in Malta" mentions don't count.

2. UNIQUE OPENING PARAGRAPH
First 200 words must be human-written or human-edited.
AI generation OK for body. AI-generated openings get 
detected as scaled content.

3. UNIQUE FAQ QUESTIONS
No copy-paste FAQ across services. Each FAQ must address 
the specific service's actual customer questions.

4. UNIQUE INTERNAL LINKING
Each page links to its SIBLING category services + parent 
money page. Not all 50 pages linking to all 50 pages.

5. NO INVENTED CASE STUDIES
If we don't have a real case study for a service, the page 
gets a generic "Our Approach" section instead. Never 
fabricate testimonials or metrics.

6. CONTENT GENERATOR REQUIREMENTS
If using AI generation pipeline:
- Output is FIRST DRAFT only, never final
- Sahan reviews every page before merge
- Track which pages are AI-drafted vs human-written
- If quality scores diverge between AI and human pages, 
  switch to human-written for next batch
