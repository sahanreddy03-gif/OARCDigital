# COPY EVERYTHING BELOW INTO BOLT.NEW:

Build a mobile-first React + TypeScript + Tailwind CSS app called PJAZZA.

This is NOT a website. This is NOT a typical app. This is a living digital world — imagine walking into Malta’s town square and everything around you is alive, streaming, pulsing, real. The user doesn’t browse PJAZZA. They ENTER it. Every element breathes. Every business is alive. Trust isn’t a feature — it’s the atmosphere.

Use Framer Motion for all animations. Use React Router for routing. Max-width 420px centered. Mobile-first PWA feel.

-----

## THE FEELING

Think: What if Airbnb was designed by the Blade Runner 2049 team but with Mediterranean warmth instead of dystopia. Warm, golden, alive — but futuristic and bold. Not cute. Not corporate. ALIVE.

## DESIGN SYSTEM

### Colors (STRICT — do not deviate):

- World background: #0D0D0F (deep void black — the “sky” of our world)
- Surface cards: rgba(255,255,255,0.06) with backdrop-blur-xl (frosted glass floating in the void)
- Warm cream panels: #FAF7F2 (for content-heavy sections — the “ground”)
- Brand gold: #C4941E (the sun of our world — primary accent)
- Honey glow: #D4A843 (warm gradient partner)
- Living coral: #E05A3A (LIVE indicators — this color PULSES, it’s never static)
- Trust green: #1A8A5C (verified, safe, money protected)
- Deep trust: #0F4A33 (dark green for trust backgrounds)
- Sky blue: #2563EB (information, property)
- Purple: #7C3AED (premium, luxury, yacht)
- Amber: #D97706 (warnings, moderate crowd)

### Typography:

Font: “DM Sans” from Google Fonts. Weights: 400, 500, 600, 700, 800, 900.

- HERO TEXT: text-5xl font-black tracking-tighter leading-none. This should feel like it’s carved into stone. Oversized. Unapologetic.
- Section titles: text-2xl font-extrabold tracking-tight
- Card titles: text-base font-bold
- Body: text-sm font-medium text-white/60
- Micro labels: text-[10px] font-semibold uppercase tracking-widest
- Stats/numbers: text-3xl font-black (numbers should feel monumental)

### Motion (CRITICAL — this is what makes it feel alive):

- Use Framer Motion everywhere
- Page enter: fade in + slide up (y: 20 → 0, opacity: 0 → 1, duration: 0.5s)
- Cards: stagger children with 0.08s delay, fade-in-up
- Live pulse: TWO concentric circles, outer pings infinitely (scale 1→2.5, opacity 0.6→0), inner stays solid. Color: #E05A3A
- Floating elements: subtle y-axis float animation (y: -4 → 4, repeat infinite, duration 3s ease-in-out) on key stats and badges
- Scroll-triggered: elements animate in ONLY when they enter viewport (use whileInView)
- Buttons: whileTap={{ scale: 0.96 }}, whileHover={{ scale: 1.02 }}
- Tab switches: content slides left/right with AnimatePresence
- Number counters: animate from 0 to target value over 1.5s when visible
- Horizontal scroll: smooth momentum, items scale up when centered (0.95 → 1.0)
- Gold gradient: animate gradient position slowly (background-position shift over 3s, infinite)

### Card Style:

- Background: rgba(255,255,255,0.05)
- Border: 1px solid rgba(255,255,255,0.08)
- backdrop-filter: blur(20px)
- border-radius: 24px
- Box shadow: 0 8px 32px rgba(0,0,0,0.3)
- On hover/tap: border becomes rgba(196,148,30,0.3) (gold glow)
- This creates GLASS CARDS floating in the dark world

### Gradients:

- Gold CTA buttons: linear-gradient(135deg, #C4941E, #D4A843) with animated shimmer
- Live sections: radial-gradient(circle at 20% 40%, rgba(224,90,58,0.15), transparent 60%)
- Trust sections: radial-gradient(circle at 80% 60%, rgba(26,138,92,0.1), transparent 60%)
- Hero: mesh gradient — overlapping radial gradients of gold, coral, and purple at low opacity on black

## IMPORTANT RULES:

1. Every transition must use Framer Motion. No CSS-only animations for important elements.
1. The app must feel like entering a WORLD, not browsing a website.
1. Dark sections (#0D0D0F) and warm cream sections (#FAF7F2) alternate to create rhythm.
1. Glass cards (backdrop-blur + transparency) are the primary card pattern on dark backgrounds.
1. Every “LIVE” indicator must pulse. Always. It’s the heartbeat of the app.
1. Numbers should count up when they enter the viewport.
1. The gold gradient (#C4941E → #D4A843) is used ONLY for primary CTAs and the PJAZZA brand. Don’t overuse it.
1. Make it responsive within 420px max-width, but it should feel native — not like a constrained website.
1. Add a subtle page transition between routes (AnimatePresence + motion.div).
1. The overall feeling: Premium. Alive. Trustworthy. New. Not a single element should feel like a template.
